## Editorial thesis

Subscription interfaces often optimize the path into recurring billing for speed while making exit more effortful. V001 shows the asymmetry using official FTC evidence and a single persistent visual world.

## Visual world

One persistent spatial system: **THE SUBSCRIPTION MACHINE**.

- LEFT — JOIN
- CENTER — RECURRING LOOP
- RIGHT — EXIT
- UP — EVIDENCE / REGULATOR
- DOWN — ECONOMICS

A single subscriber token moves through the system. The world never resets; camera framing changes instead.
