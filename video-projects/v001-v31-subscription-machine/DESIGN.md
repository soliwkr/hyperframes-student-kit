# V001 V3.1 — Editorial Motion Contract

## Design idea

A restrained investigative diagram that gradually reveals itself as a subscription machine.

The visual identity comes from:
- spatial continuity
- evidence
- typography hierarchy
- one travelling subscriber token
- deliberate camera moves
- quiet context vs active spotlight

It must not look like a generic "dark tech" AI explainer.

## Palette

- Canvas: #F4F1EA
- Raised paper: #FCFAF5
- Ink: #171717
- Muted ink: #6F6B63
- Rule: #D6D0C5
- Evidence blue: #2359D6
- Warning red: #A63A32
- Money green: #2E7551

Color is semantic:
- blue = source/evidence
- red = friction/allegation/status
- green = recurring money loop

## Type

- Display: Newsreader
- UI/body: Inter
- Evidence/meta: IBM Plex Mono

## Layout

1920×1080.

The machine occupies a wide world larger than the viewport. Camera translation/scale reveals:
1. evidence
2. join lane
3. exit lane
4. economics loop
5. whole-system payoff

## Spotlight

At any beat:
- active: opacity 1
- context: 0.48–0.62
- spent: 0.28–0.38
- not introduced: 0

No more than one primary focal element.

## Motion

- Camera moves are the edit.
- Use power2.inOut for visible world moves.
- Element entries may use expo.out.
- Exits are faster than entrances.
- No bounce/elastic.
- No gratuitous whip transitions.
- No constant idle motion.
- No random animation.

## Evidence plate

Every source card contains:
- institution
- date
- document/page title
- exact claim or number
- status badge: SETTLED / ALLEGED / REPORT / RULEMAKING
- source domain

## Forbidden

- neon/cyberpunk
- fake browser chrome
- generic AI faces
- fake screenshots
- dramatic cinematic HUDs
- giant subtitles for every sentence
- continuous whooshes
- decorative 3D glass
